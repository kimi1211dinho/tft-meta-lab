# MetaScope TFT prototype

APIを使わず、Set 18のプレビュー用サンプルデータで動作するTFT分析ダッシュボードです。

## 起動

`index.html` をブラウザで開いてください。ビルドやインストールは不要です。

## 実装済み

- 地域・期間フィルター
- グローバルランキング
- LP急上昇プレイヤー
- プレイヤー検索と直近試合ダイアログ
- 駒・アイテム分析
- 駒ごとの理想3装備と代替候補
- アーティファクト別の推奨装備先ランキング
- シナジーと併用構成
- PC・タブレット・スマートフォン対応

表示値とプレイヤー名はデモ用の架空データです。`app.js` のデータ配列を、将来CSV・データベース・Riot APIなどへ置き換えられます。
